# Community Code of Conduct

We want GTA VI RP Platform to be an inclusive, technically rigorous community where contributors can collaborate respectfully, regardless of experience or background.

## Expected behavior

- Be constructive, precise and respectful when proposing or reviewing changes.
- Discuss code and ideas rather than attacking people.
- Welcome beginners, ask for reproducible examples and document decisions.
- Respect contributor privacy, intellectual property and security boundaries.
- Credit work accurately and resolve disagreements through evidence and reasoned discussion.

## Unacceptable behavior

- Harassment, discrimination, threats, personal attacks, stalking or doxxing.
- Sexualized harassment or deliberately hostile conduct.
- Sharing secrets, private data, game leaks, pirated assets or unauthorized access instructions.
- Publishing exploit details or abusing the project to target a game service or another person.
- Repeated spam, trolling, or deliberately misleading compatibility claims.

## Where this applies

This applies to GitHub issues, pull requests, reviews, project discussions and other spaces presented as part of the project.

## Reporting and enforcement

For ordinary conduct concerns, contact the repository maintainers privately through an appropriate GitHub channel. Do not post personal information or harassment evidence publicly. For code vulnerabilities, use the private procedure in [SECURITY.md](./SECURITY.md).

Maintainers will assess reports impartially and may ask for changes, hide or remove contributions, lock discussions, or restrict participation. Repeated or serious violations can lead to permanent removal. We aim to provide an explanation to affected parties where doing so does not compromise privacy or safety.

This policy does not grant the project authority over the wider Grand Theft Auto community.
