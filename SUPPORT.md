# Support and Questions

This repository currently provides **source code, documentation and early simulator tooling**. It does not provide a GTA VI multiplayer client, server, installer, gameplay support or an official Rockstar service.

Spanish version: [Soporte y preguntas](./SUPPORT.es.md).

## Choose the right channel

- **Reproducible project bug:** [open a bug report](https://github.com/smouj/calm-rp-framework/issues/new/choose) with steps, revision and expected/observed behavior.
- **Feature or architecture proposal:** use the feature proposal issue form.
- **Public research finding:** use the platform research issue form, cite a primary source and explain the limits of the claim.
- **General questions and community chat:** join the [project Discord](https://discord.com/invite/BVWXWY5eUT). For searchable proposals or decisions, use [GitHub Discussions](https://github.com/smouj/calm-rp-framework/discussions). Do not post personal details, sensitive conduct reports or security vulnerabilities in Discord channels.
- **Security vulnerability:** follow [SECURITY.md](./SECURITY.md), **not** a public issue.
- **Rockstar game/account problems:** use Rockstar's official support channels; this project cannot provide account, game purchase or multiplayer support.

When sharing logs, remove secrets, personal information, access tokens, game assets and any proprietary payloads. A short synthetic reproduction is preferred.
