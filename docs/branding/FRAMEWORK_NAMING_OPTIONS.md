# CALM — framework brand decision (working identity)

**Decision date:** 24 November 2026. **Selected by the project owner:** **CALM**. Descriptor: **Roleplay Framework**.

CALM was chosen deliberately as a contrast in _tone and naming_ with RAGE, Rockstar's game engine. **CALM does not run RAGE, replace it, or currently offer an interface to GTA VI.** This naming rationale does not imply partnership, reverse-engineering authority, interoperability or a Rockstar license.

## Product identity

- Public-facing working name: **CALM**
- Descriptive line: **Independent Open-Source Roleplay Framework**
- Short tagline: **Build the roleplay. Keep the core independent.**
- Website wordmark: **CALM / RP FRAMEWORK**, in original typography and colors
- GitHub repository and existing TypeScript workspace names: **unchanged for compatibility** (`smouj/gta6-rp-platform`, `@gta6-rp/*`)
- Technical API naming: **unchanged** until a versioned deprecation/migration plan
- No official Rockstar game media, logos, RAGE mark or derivative brand assets in CALM's logo

## Naming collision and trademark warning

**Do not present CALM as a legally cleared or exclusive software mark.** Public research performed on 24 November 2026 found:

1. **FINOS CALM** (Common Architecture Language Model) is an established open-source software-architecture specification, tooling ecosystem and documentation site. Sources:
   - https://calm.finos.org/introduction/what-is-calm/
   - https://github.com/finos/architecture-as-code
2. **Calm.com / CALM** uses the name for downloadable applications and software and has documented trademark registrations in multiple territories. These are not automatically the same market or a proven infringement; they **are** a reason to do diligence:
   - https://trademarks.justia.com/869/84/calm-86984393.html
   - https://www.trademarkelite.com/wipo/trademark/trademark-detail/1523964/CALM

These searches are preliminary **references**, not a formal full clearance. Review EUIPO TMview, OEPM, WIPO, company/product names, software registries, GitHub organization names, package scopes, domain names and confusingly similar marks with appropriate expertise. The brand may need a more distinctive qualifier or redesign if a material conflict exists.

## Legal and engineering restrictions

CALM is an independent project, not Rockstar/Cfx/FiveM/FINOS/Calm.com software or an authorized GTA VI client/server. A game-specific adapter will be developed **only** if a documented and legitimate integration pathway exists.

The repository's MIT license covers only our original code and approved project files, not names or works owned by Rockstar or other rightsholders. No third-party logos, trademark graphics, archive files, executables or leaked game data may be included.

Do not rename code packages, npm scopes or repository URLs in the same step as brand adoption. A separate versioned change must include dependency migration tests, compatibility and rollback notes.
