# Independent framework naming workshop — revision 24 November 2026

**Decision:** OPEN. No new brand, trademark, package namespace or domain is claimed. The repository stays `gta6-rp-platform` until the maintainer chooses an independent identity after availability checks.

## Identity requirements

- One memorable word, ideally 5–8 characters and readable in Spanish and English.
- Must function as a **framework brand**, distinct from the project’s research subject: avoid GTA, Rockstar, Vice City, FiveM, Qbus/QBCore/Qbox or ESX in the brand.
- Should support modular package and resource prefixes, for example `teldaro-core`, `teldaro-economy`, `teldaro-inventory`, **only after a final decision**.
- No claim of GTA VI compatibility, endorsement or licensed multiplayer runtime.

## Exact final-approval procedure

1. Pick a maximum of 2–3 candidates for detailed evaluation.
2. Search EUIPO [TMview](https://www.tmdn.org/tmview/), the Spanish [OEPM](https://www.oepm.es/), and relevant international trademarks in software/gaming/community service classes and confusingly similar spellings.
3. Check GitHub organization/user names, npm and other package registries, domains and social handles.
4. Consult a qualified trademark practitioner if the project will go public, run community services or monetize.
5. Choose the brand, its short description, resource prefix, logo direction, README labels and package migration policy **then**, not beforehand.
6. Keep official Rockstar trademarks solely as non-affiliation/context notices, with no use in the framework's original mark.

## Provisional ranking

**Teldaro** is the current *naming-workshop front-runner* for its phonetics and product-neutral feel, followed by **Seldria** and **Neldra**. **No final name has been assigned**; these recommendations remain conditional on further legal and ecosystem checks.

The existing repository URL can remain stable during a gradual naming transition.
