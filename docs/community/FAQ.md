# Frequently Asked Questions

## Can I play GTA VI roleplay with this today?

**No.** This repository does not provide a working GTA VI multiplayer client, server or installer. It develops game-independent RP logic and documentation.

## Is this an official Rockstar or Cfx.re project?

**No.** It is independently developed by fans and contributors. GTA VI and other protected Grand Theft Auto content remain the property of the rights holders.

## Is this a fork of FiveM?

**No.** We are inspired by the collaborative possibilities of FiveM, but there is no FiveM code, compatible client or confirmed GTA VI runtime integration in this repository.

## Can the community eventually create a FiveM-like platform for GTA VI?

It is a long-term aspiration. Technical feasibility, supported development interfaces, ownership rights, platform terms, multiplayer security and runtime authorization must be independently established before making that claim.

## Why are you writing TypeScript before knowing GTA VI's scripting runtime?

The game-independent domain, simulator, tests and web tooling can use TypeScript today. A possible future game-facing adapter would use whichever officially supported interface is appropriate, if one becomes available.

## Does Leonida prove GTA VI supports community servers?

**No.** Third-party research into game file formats, graphics or offline tooling does not establish an authorized multiplayer client/server runtime.

## Do I need to own GTA VI to contribute?

**No.** The simulator and checks use project-owned or synthetic data. Do not upload game files.

## Can I use the code in my own project?

The repository's original code and documentation are licensed under [MIT](../../LICENSE), subject to their own attribution and license terms. That does not license Rockstar game assets or trademarks, and it does not provide GTA VI multiplayer support.

## How can I help if I do not code?

Review documentation, translate, improve accessibility, propose reproducible UX tests, validate public sources, and suggest bounded improvements through the issue forms.

## Why is GTA VI integration marked blocked?

There is no verified, authorized implementable runtime contract in the project's source-of-truth research. We explicitly record unknown requirements rather than inventing functions, network protocols or compatibility claims.

## Where do I report a vulnerability?

Read [SECURITY.md](../../SECURITY.md) and use private reporting if enabled. Never submit secrets or exploit details to a public issue.
