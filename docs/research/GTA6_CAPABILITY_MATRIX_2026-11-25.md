# GTA VI capability matrix — verified research catalog

**Compiled:** 25 November 2026. **Method:** public third-party research repositories and
media reports only; no leaked builds, executables, keys or game files were downloaded, run
or incorporated. Every row cites its upstream project and the observation date.

This is the catalog required by the research mission (Phase 3). It records what public
reverse-engineering has actually demonstrated about GTA VI's RAGE 9 technology, at what
confidence, with which limitations, and what each finding means for CALM's architecture.

## Confidence taxonomy

| Level                        | Meaning                                                                                                                              | Maps to repo class           |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------- |
| `CONFIRMED`                  | Public first-party Rockstar/Take-Two/Cfx.re statement                                                                                | `CONFIRMED`                  |
| `THIRD_PARTY_REPRODUCIBLE`   | Third-party finding with published methodology, self-tests or open tool code that could in principle be re-run on legally owned data | `PUBLIC_OBSERVED`            |
| `INDEPENDENTLY_CORROBORATED` | Two or more independent clean-room implementations converge on the same structure/behavior                                           | `PUBLIC_OBSERVED` (stronger) |
| `INFERENCE`                  | Reasoned planning assumption                                                                                                         | `INFERENCE`                  |
| `RUMOR`                      | Unverified claim                                                                                                                     | `RUMOR`                      |
| `UNKNOWN`                    | Not publicly established                                                                                                             | `UNKNOWN`                    |

A format finding at any third-party level **is not** a callable GTA VI scripting API, a
server contract, or an authorization. No row below promotes any `RT-*` requirement in
`docs/server/RUNTIME_REQUIREMENTS.md`.

## Reading rules (unchanged)

1. **Format knowledge ≠ execution capability.** A decoded structure is evidence about data layout, not about a callable API, server authority or synchronization.
2. **Self-reported results stay third-party** until an independent party re-runs them; we record methodology so anyone with legally owned data could.
3. **Leak-derived artifacts are non-admissible inputs** for CALM (policy: `THIRD_PARTY_ARTIFACT_POLICY.md`, `LEGAL/INTEROPERABILITY_AND_IP_REVIEW_2026-11-24.md`).
4. No row above changes any `RT-*` state; `GTA6_UNVERIFIED_CAPABILITIES` remains empty by design.
5. Every row must be re-checked before citing: record upstream revision/commit and observation date (see `THIRD_PARTY_TOOLS_SNAPSHOT_2026-11-24.md` for the pinned-revision method).
