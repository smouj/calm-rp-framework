CALM / GTA VI RP / SISTEMAS PROPIOS

CALM Essentials: roleplay pensado para GTA VI.

CALM Essentials es un proyecto GTA VI-first. Diseña sistemas de roleplay propios a partir de mecánicas públicas observables y de las necesidades de su comunidad; no adapta ESX, QBCore, Qbox ni FiveM. F1 aporta la base persistente de identidad, sesiones y economía; el cierre de API y seguridad sigue pendiente. F2 completó inventario y almacenamiento persistentes. El runtime de GTA VI sigue bloqueado.

Cómo está diseñado →Ver código ↗

No oficial · Sin archivos del juego · Sin cliente ni servidor multijugador GTA VI

Sin afiliación ni autorización de Rockstar Games o Take-Two Interactive. La licencia MIT cubre exclusivamente el código original; la web no permite jugar ni descargar GTA VI.

01 / ARQUITECTURA

El objetivo es GTA VI. La integración sigue bloqueada.

CALM define reglas propias para la experiencia de roleplay que busca en GTA VI. El comportamiento público del juego orienta sus requisitos; el simulador valida las reglas de CALM. Ninguna de esas pruebas conecta con el juego ni demuestra compatibilidad.

Postura de integración. La investigación pública puede orientar el diseño de sistemas RP propios; no establece APIs, servidores comunitarios ni permiso para conectar CALM con GTA VI. Síntesis de estrategia GTA VI ↗

02 / SISTEMAS

Sistemas propios para GTA VI RP. Sin clonar GTA V.

Consulta qué hace cada sistema de CALM y qué estado tiene realmente.

01IMPLEMENTADO · F1

Personajes

Identidad aislada por cuenta; registro validado y detección de duplicados. Sesiones autenticadas y persistencia PostgreSQL entregadas en la base F1; queda trabajo de cierre de API y seguridad en la incidencia #32.

packages/core + persistence · F1
02IMPLEMENTADO · F1

Economía

Saldo en unidades enteras, transferencias idempotentes, libro de movimientos y propiedad comprobada. Contabilidad de doble entrada persistente y prueba de concurrencia entregadas en F1.

packages/core + persistence · F1
03IMPLEMENTADO · F2

Inventario

Servicio persistente para cargar, consumir, almacenar, recuperar e intercambiar objetos. La propiedad permanece separada de la ubicación; equipamiento y loadout son otro dominio. No se conecta con GTA VI.

FUENTE OFICIALOpciones y estados ↗

Rockstar documenta categorías de ajustes y estados del jugador, no fórmulas internas ni un contrato de servidor.

CALM es el framework; la investigación de compatibilidad es externa

CALM define sus propios dominios y contratos RP. Los informes sobre ports de PC, emuladores, formatos y repositorios de terceros se mantienen en un archivo documental independiente; no forman parte de la arquitectura, dependencias ni implementación de CALM. El adaptador GTA VI sigue bloqueado hasta que exista una vía oficial y autorizada.

05 / DIRECCIÓN
