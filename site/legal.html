TRANSPARENCIA / AVISO LEGAL

Independiente por diseño.

Esta página describe el estado y los límites de un proyecto comunitario de software. No es un producto, servicio o canal oficial de Rockstar Games, Take-Two Interactive ni Cfx.re.

01. Titularidad y ausencia de afiliación

«Grand Theft Auto», «GTA», «GTA VI», sus logotipos, personajes, obras de arte, música y demás contenidos protegidos pertenecen a sus respectivos titulares, incluidos Rockstar Games y Take-Two Interactive. El uso de sus nombres en este sitio es descriptivo y no implica patrocinio, asociación, aprobación ni autorización.

Los elementos gráficos y el código originales de este proyecto son independientes. No utilizamos marcas o imágenes oficiales como identidad propia del proyecto.

02. Qué existe y qué no existe

Se desarrolla un núcleo experimental de roleplay con código propio, contratos abstractos y un simulador independiente. Este sitio no ofrece un cliente, servidor dedicado, modificación, instalador, API nativa, multijugador funcional ni acceso anticipado a GTA VI.

Las API documentadas de FiveM, Cfx.re, QBCore, Qbox u otros productos se citan solo en el contexto del producto al que pertenecen. No prueban compatibilidad con GTA VI. Las investigaciones sobre RAGE 9 publicadas por terceros tampoco constituyen un SDK, una API de scripting ni una autorización para modificar juegos.

03. Código abierto, licencias y contenido prohibido

La licencia MIT del repositorio se aplica exclusivamente al código y documentación originales que efectivamente se publiquen bajo dicha licencia; no licencia el juego, sus archivos, marcas o derechos de terceros. Cada dependencia de terceros está sujeta a su propia licencia.

No distribuimos ni enlazamos descargas de ejecutables filtrados, paquetes de consola, modelos, mapas, audio, texturas, claves, scripts extraídos o cualquier otro contenido propietario no autorizado.

04. Condiciones de Rockstar y límites jurídicos

El desarrollo independiente de interfaces conceptuales no significa que exista permiso para alojar servidores de GTA VI. Una eventual integración deberá cumplir las licencias, condiciones de uso y directrices vigentes, y contar con una vía técnica legítima y autorizada. Las excepciones legales de interoperabilidad tienen requisitos y límites; no otorgan permiso general para redistribuir obras protegidas o eludir controles de acceso.

Consulta las directrices oficiales sobre modificaciones, la política oficial de servidores RP, la Directiva 2009/24/CE y la Ley de Propiedad Intelectual española. Este texto es informativo: no equivale a un dictamen jurídico ni acredita la conformidad legal de una publicación o integración futura.

05. Datos del sitio web

Esta web estática no incluye formularios que envíen datos al proyecto, cuentas de usuario, operaciones económicas ni analítica propia. Las funciones interactivas se limitan a la alternancia del tema, el filtrado de módulos y la copia del comando de clonación; la preferencia de tema se guarda localmente mediante localStorage.

El alojamiento de GitHub Pages puede tratar datos técnicos de acceso conforme a las políticas de privacidad de GitHub. Los enlaces a terceros abren sus respectivos sitios y pueden estar sujetos a otras políticas.

06. CALM como nombre de trabajo

CALM es el nombre de trabajo elegido para este proyecto independiente por contraste conceptual con el motor RAGE de Rockstar; esa referencia no implica relación técnica o comercial. CALM no se presenta como una marca registrada exclusiva: ya existen usos tecnológicos del término, entre ellos el estándar abierto Common Architecture Language Model de FINOS, y marcas de terceros. El lanzamiento de una identidad comercial requiere revisión de posibles conflictos de marca, denominaciones y dominios.

07. Investigación y cambios de estado

La documentación clasifica las fuentes en información oficial, declaraciones de terceros, hipótesis y capacidades desconocidas. Un cambio de compatibilidad o autorización solo podrá anunciarse cuando exista evidencia verificable. La denominación CALM está elegida como nombre de trabajo, pero su uso como marca comercial queda sujeto a revisión de derechos de terceros.
